# Prepared async raster and cleanup contracts

This is SOURCE-ONLY work. All new causal cases and public installed consumers are UNRUN. The canonical Earth app, dependencies, frozen artifacts and remote admission settings remain unchanged.

`@foss-earth/engine/babylon` publicly exports `GlobeFramePreparation` from its existing `export type * from "./globeRuntimePorts.js"`. Supply `GlobeRuntimeOptions.framePreparation = {prepare(frame) {...}}` for an ordinary host contribution. Engine invokes that method once after camera/map work and the legacy external callback, before Sky. Its receiver is the supplied contribution object. `frame.nowMs` is the current monotonic host timestamp in milliseconds; `frame.deltaSeconds` is the existing renderer delta in seconds with the retained 1/240 second floor; `frame.scene` is borrowed. The contribution can prepare the host's existing uploader, transfer tracker or viewer and request a frame through that same authority. It creates no clock, scene, renderer or scheduler. A throwing contribution closes the current Engine boundary. Disposal during it suppresses subsequent Sky work. Existing external callback signatures/order remain available.

For per-mesh maps, supply `RasterTilesRuntimeOptions.asyncMapTextures` (also exposed by `GlobeRasterPorts`):

```ts
interface AsyncRasterMapTextures {
  resolve(source, tile, builtUrl): {
    file: ImageFile; // actual URL, JPEG/PNG MIME and pixel dimensions
    declaredBytes: number;
    priority: number;
  };
  acquire(file, request: BoundedMapTextureRequest): Promise<LoadedMapTexture>;
  createAbortController(): AbortController;
}
```

Methods keep their supplied object receiver. Metadata is an explicit host contribution: existing source descriptors do not specify MIME. Engine copies the returned file record before acquisition. No URL extension, provider name or default MIME is used to infer it. `acquire` must resolve only after actual readiness and clean unpublished resources on rejection. Its request receives the record cancellation signal, priority, encoded byte estimate, progress callback and overlap flag. The host binds the one `createBoundedMapTextureLoader` to its existing common files/broker/uploader/readiness ports; the public-only binding example is `fixtures/composition/asyncMapTexturesHost.ts`.

Async acquisition takes precedence over the legacy synchronous factory. Hosts can omit `loadMapTexture` when supplying the async port; old synchronous callers remain compatible. Neither port changes the default atlas/legacy selection. The runtime requires at least one explicit per-mesh acquisition port so fallback transitions cannot silently construct another loader.

Incoming handles must be current, 2D and from the same scene. Engine sets the original CLAMP U/V and live anisotropy. The bounded loader retains `textureColor:{useSRGBBuffer:false,gammaSpace:true}`, invertY=false, trilinear sampling and mips where legal. The old material stays bound while replacement acquisition/readiness is pending. In one task Engine assigns the ready incoming material/handle, releases the outgoing handle, acknowledges incoming overlap and requests the existing frame. Elevation requests and surface revision are not changed by this swap. If outgoing disposal throws, new pixels remain bound and the overlap acknowledgment is withheld conservatively until incoming ownership is eventually released; the failure reaches the supplied error observer. Engine does not advertise uncertain native cleanup as completed capacity handback.

Source replacement retires the earlier publication token before host abort. Record/runtime disposal cancels every pending request even if earlier terrain/material cleanup throws. Late handles are disposed without publication. Initial metadata/acquisition failure settles after cache insertion and follows the existing retry/wake policy. Replacement failure keeps outgoing content. A throwing error observer cannot strand initial settlement; its failure is reported to the supplied logger after all resource cleanup is attempted. Diagnostic failures have no resource/frame authority.

`createBoundedMapTextureLoader` now requires the common decoded handle's `retain()` before invoking a potentially delayed uploader. Native input and its existing decoded-pixel reservation survive scope cancellation until upload finishes and late cleanup is attempted. Supplied legacy decoders without this reliable port reject the bounded route; the old synchronous compatibility entry remains available. Direct native upload/staging grants still outlive scope cancellation and stay renderer-owned until completion or observed device loss.

Owned cleanup retires references and attempts every release independently. A single failure keeps its identity; multiple failures use causal `AggregateError` order. This covers clipping and both owned cameras, fallback mesh/material/light allocation rollback, fallback mesh/light disposal, imagery timer/native restoration observer/residency/patch bindings/current and retired atlases, and partial atlas/table allocation. Borrowed scene/backend/Sky/settings/profile/lifecycle/clock survive. `ImageryRuntimeOptions.releaseOwnedLoader()` is the only loader ownership transfer: omitted means borrowed, including a loader with a `dispose` method. Supply it only for a dedicated adopted loader; the host owns any override selection. Runtime disposal is idempotent. The native imagery context-restored observer remains present, resets bookkeeping before supplied cancellation and still attempts the host wake after a reset failure; queued/stale restoration and wake callbacks are suppressed after disposal.
