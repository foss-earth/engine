# Engine source contracts

This is an unvalidated source draft at staging `@foss-earth/engine@0.1.0`. Immutable source is Earth `90e23b3ee96f53ec5900afc5991a21fffa58649d`; dirty physicalHeight, weather, atmosphere and package inputs are excluded. `extraction-provenance.json` records source blob/SHA256 and transformed destination hashes. No built declarations, archive or release pin is claimed.

`GlobeViewState` retains `latDeg`, `lonDeg`, `headingDeg`, `pitchDeg`, `zoomMeters`. Navigation snapshots are serializable version 1: ECEF centre metres, yaw/pitch/FOV radians and orbit radius metres. Presentations use ECEF position/forward/up and vertical FOV radians. Handback motion retains eye velocity m/s, look derivative 1/s, fovRad, inputSince in the shared monotonic host clock's milliseconds and an optional still-held press.

`createNavigationOwner(host)` requires focusReturn, createAbortController, abortReason, unavailable, snapshot, suspend, resume, present, requestRender, beginContinuous and endContinuous. Core cancellation/focus are structural. `createBrowserNavigationOwner` binds the supplied document/cancellation realm. A lease holds the existing renderer authority; it creates no scheduler.

`createInertialCameraController(target,{nowMs,decayPerFrame})` preserves source velocity accumulation/clamps/stop thresholds and per-60-Hz decay. `createGlobeInertia(controller,ports)` retains the source request-on-input and anchor-grab behavior. Both use the one live `camera.inertiaDecay`. `createNavigationCameraAdapter` exposes exact capture/restore/place/glide/FOV return and one-shot `takeInputHandback`; the host must apply that handback to the existing input controller when resuming. The host owns active-camera choice, input/map suspension, navigation-layer presentation mask and continuous-render tokens.

`createGeospatialGlobeCamera` initializes the retained globe camera and removes Babylon pointer/wheel inputs, preventing duplicate gestures. It uses the supplied scene/backend and does not select `scene.activeCamera`. `createCameraClipping` consumes renderer-owned clipping parameters without owning their catalogue. `createGlobeIntentMotion` uses explicit live rates. Source controller rates are retained as visible, unmeasured starting values: pan 900 px/s, heading 75 deg/s, pitch 65 deg/s, zoom logarithm 1.5 per-s; their homes are Controls → Controller.

`createDisplayedSurfaceAccess(query,{readiness})` makes hit/missing, revision and readiness explicit. `SurfaceHit.heightMeters` is the WGS84 ellipsoid coordinate height of the displayed geometry. `height.physicalDatum` is always `unknown`; this adapter performs no provider/geoid conversion. Loading may retain outgoing drawable geometry. Invalid input, unavailable/failed geometry, real miss and changed revision have distinct results. The Babylon surface query preserves finite rays, visible map-only geometry, floating-origin transforms and authoritative indexed raster misses.

`createRasterTilesRuntime` retains source terrain/imagery generations, caching, selection, focus, readiness, smoothing/seams, retries, live budgets and automatic detail. It requires the host registry, nowMs, after, requestRender, meshRebuildCpuMs, an explicit legacy or optional async map texture port, terrain loader factory, terrain lighting attachment and atlas device/capability/acquisition/cancellation ports. Legacy gamma/filtering is retained through renderer's public `createPendingImageTexture`; maps do not inherit panorama queue capacities. `map.terrain.meshRebuildTimePerFrame` exposes the source's formerly fixed 2 ms yield (ms, 0.25..16, default 2, Map → Terrain selection); this is not a device measurement.

`ImageryAtlasDevicePorts` matches renderer's public `TextureDevicePorts`: generic createRawTexture and updateTextureData on the same supplied scene/device. The renderer host's one `createTextureTransferTracker({scene,admit,requestRender})` provides that transfer callback, admits bytes before submission and retains the grant through device completion; the host pumps it on its existing frame and calls deviceLost only on actual loss; engine retains atlas layout/slot/table/residency policy. The composition fixture consumes actual renderer `createTextureDevicePorts`, not a copied device body.

`createGoogleTilesRuntime` takes supplied 3D Tiles renderer/auth factories, cancellation/signal combination, public whenMeshesReady bound to host policy, terrain-light receiver, response realm, download/request logging, resource timing and online/origin observations. Hidden model parsing remains pending until mesh readiness or cancellation, preserving the outgoing LOD. No backend or second readiness loop is constructed by engine.

`createTerrainLightingAdapter(ports)` receives Sky's table configuration, groundLightAt and night-map constants through app composition. Its CPU factors/material GLSL/WGSL and scoped scene lighting/local/night receivers are retained. `MaterialPlugin` is the scoped actual constructor, with no module singleton and no engine-to-Sky production import. Original engine+Sky test fixtures use only Sky's public root.

`LocationPanel` applies plain coordinates/place results through onApply and preserves editing, live placeholders, result expansion/retry/cancellation/offline snapshots and storage errors. `LocationPanelContribution` owns domain selection/apply/render/blocked/hide-coordinate behavior. `LocationHostDataCodec` must explicitly validate/copy contribution data. Missing codecs are rejected for snapshots; no aircraft payload is silently reinterpreted. See the exact [flight handoff](adoption.md).

The optional [Location provider](location-provider.md) preserves the existing `foss-earth.location-lookups.v1` rows, aliases, TTL/LRU behavior and `search.*` settings at Interface → search. The host creates one cache/provider queue and contributes query suffix/result metadata; no deferred Search tab/repository or aircraft placement implementation is included. Map/Controls forward their supplied Document into the current required UI factory options, including choice groups/notes, sections and tracks. These contracts need new checked UI source artifacts; an older frozen archive is not equivalent.

The [cache presentation](map-cache-presentation.md) keeps the React MapCachePanel source behavior with required public cache inspect/clear and shared refresh/visibility/clock/policy props. New `MAP_CACHE_PRESENTATION_PARAMETERS` owns `map.cache.rowsShown` (count, default 40) and `map.cache.inspectInterval` (ms, default 2000) at Map/loading/all; the host binds `createMapCachePresentationPolicy` to its one registry and supplies the same row getter to the existing DOM section. Actual snapshot.maxBytes replaces the fixed 128 MB note. Clear/inspection/detach fixtures and installed public React/CSS adoption remain UNRUN.

The exact [visualization and bounded-map contracts](visualization-contracts.md) describe disposal, settings homes, source defaults, late upload ownership and compatibility limits. Common images 0.1.0 is a production dependency; no representation implementation is imported.

The full [borrowed globe runtime](globe-runtime.md) retains original methods while requiring explicit owner authorities and terrain acceptance policy. Sky 0.1.0 is an optional public type peer; the host alone constructs/binds/disposes its actual implementation.

Exact optional production peers are Babylon 8.56.2, renderer/UI 0.1.0, gamepad-tools 0.1.0, 3d-tiles-renderer 0.4.24 and React 19.2.4. Sky 0.1.0 is an optional public type peer and a composition-test dependency; the host owns its runtime. Engine release/artifact/admission results remain pending; the primary-staged shared attribution pins appear in README and the source receipt. The nine [immutable Engine specifications](retained-specifications.md) retain historical/proposal prose without asserting their acceptance criteria were newly implemented.

The current [async raster, ordinary frame and cleanup renewal](async-raster-and-cleanup.md) documents actual public ports, ownership/compatibility changes, causal source cases and remaining Atlas/native/cache gates. All remain UNRUN.

The [bounded Atlas producer](bounded-atlas-producer.md) documents actual public constructor/managed lifetime ports, fourth request priority, typed missing classification and deliberate native upload refusal. `PreparedImage.close/retain/isCurrent` are optional for legacy compatibility; the bounded producer supplies all three, and actual residency closes them on retirement. `ImageryOwnedUploadUnsupportedError` is public through `./imagery`. Current void native store cannot establish retirement or complete-batch success; no new owned native protocol implementation exists.
