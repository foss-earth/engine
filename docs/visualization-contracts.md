# Visualization and bounded-map source contracts

These are prepared source APIs at `@foss-earth/engine@0.1.0`, with no emitted artifact or passing check claimed. The immutable behavior source is Earth `90e23b3ee96f53ec5900afc5991a21fffa58649d`. New causal tests and installed fixtures are unrun until the coordinator grants checks.

## Layers, points and culling

Root/core exports the pure `GlobeLayerContext {scene:unknown,engine:unknown}`, `GlobeLayerState` and `GlobeLayer` contracts. `GlobeLayer` retains `id`, `setup(context)` and `destroy(context)`; `GlobeLayerState` retains its generic source extension fields. `./layers` supplies Babylon-specific `BabylonLayerState`, `PoiDescriptor`, `createLayerRegistry(context,poiTracking,culling?,anchorHeights?)` and `createPoiTracking(scene,getCamera,options?)`. No app-handle singleton is imported. Registry replacement destroys the prior same-ID layer and rebuilds the supplied POI, culling and anchor-height collections. It retains source synchronous teardown/error behavior rather than inventing transaction rollback.

POI tracking accepts live `dragThresholdPx`, `requestRender` and `log` ports. It selects only mouse clicks, observes the supplied scene, exits when a tracked point disappears and suspends clicks/following/programmatic entry while navigation owns the camera. Destroy is idempotent, removes observers and invokes a final tracking-exit callback. Source entry immediately sets the orbit centre to the point, and following updates it before the existing scene renders. This is an observed camera snap, with no new momentum-qualified move claimed. Moving points and visibility changes still need the host's existing frame authority.

`./visualization` and root export pure `DEFAULT_POI_SPRITE_SIZE_PARAMS`, `DEFAULT_ORBIT_COMPASS_SCALE_PARAMS`, marker metadata/helpers, tile-index/refinement/size math, `VISUALIZATION_MIGRATIONS` and `createHemisphereCulling(getCameraPosition,policy?)`. No Babylon or browser global is required to import them. The default horizon margin is `0.03`; a host may supply `policy.horizonMargin()`. Every current point/polyline is scanned and original total/visible/hidden statistics are retained. This is a spherical horizon using the WGS84 equatorial radius, not an ellipsoid occlusion algorithm or bounded-batch scheduler.

Point refinement retains source defaults: max camera distance 120000 m, upward/downward probes 20000/40000 m, distance bands 5000/20000/60000 m with terrain levels 17/16/15/14, and tile-radius bands 10000/45000 m with radii 1/2/3. `poiRefinementPolicyFromSettings(get)` reads the explicit host values. Preserve near-to-far distance order; no cross-field auto-reordering is implemented. `poiRefinementLod` also accepts its legacy numeric max-distance argument. `samplePoiMeshPosition` uses only the supplied scene and explicit probe distances; its source mesh predicate does not establish a physical terrain datum.

## Atlas, sprites and compass

`./sprites` exports `makeCircularMarkerAtlas(device,name,styles,cellSize=64)`, `createPointSpriteManager(options)`, `createPointSprite(options)`, picking, sizing and point positioning. `device` is the actual public renderer `CanvasTextureDevicePorts`; the host constructs it with its existing scene, explicit canvas factory and one broker-backed transfer tracker. The atlas creates one horizontal non-mipped texture and uploads after drawing all cells. Failure disposes that texture. `createPointSpriteManager` retains the actual supplied-scene Babylon semantics and transfers atlas ownership to the manager. Its `minCapacity` is explicit; legacy default remains 32000, and capacity is the maximum of this floor and actual point count. Teardown disposes sprites/managers; it does not create a private device, decoder, cache or clock.

`./compass` exports `createOrbitCompass(scene,{device,labelTextureSize?,requestRender?})`. Default label side is 128 px. Four letter textures use source mipmapped/invertY behavior. `drawText` disables its implicit update, then the supplied device performs the admitted update. Source geometry, radius/size defaults, anchor/radius tolerances and fade behavior are retained. Setup failure tears down already-created meshes/textures. `destroy()` releases owned meshes/materials/textures and late calls are inert. Visible geometry/fade/visibility changes request a host frame; repeating the same update does not request idle frames. No dedicated frame loop is installed.

## Settings and tuner panels

`./settings` exports `ENGINE_VISUALIZATION_PARAMETERS` and `ENGINE_POINT_RESOURCE_PARAMETERS`. The source eleven records preserve IDs, source defaults, descriptions and homes: `visualization.compass.heightOffset` is Controls → Camera; compass size, POI size and `interface.poiSpriteTuner`/`interface.compassScaleTuner` remain Renderer → Performance. These are documented engine-owned host contributions to existing tabs. Resource controls expose the former fixed sprite floor, atlas cell, label texture, horizon margin and POI probe/LOD/radius policies using count, px, ratio or m units. Hosts read/apply the corresponding values through the explicit ports; no global registry is constructed.

`./visualization-tuners` exports both `createPoiSpriteSizeTuner(container,onApply,{document,settings})` and `createCompassScaleTuner(container,onApply,{document,settings})`, plus saved-value helpers and `VisualizationTunerPorts`. The settings port provides `get`, `inspect` and `setMany`; all DOM nodes come from the supplied document. Initial saved values are applied on mount. Apply updates the live callback; Save accepts new persisted defaults only when `setMany` succeeds. Rejected writes retain the pending Save state. Show/hide/destroy semantics and numeric form controls are retained; destroy removes listeners and late events/calls are inert. Panels snapshot saved settings on mount; the host refreshes/recreates after external edits. `./visualization-tuners.css` uses wrapping paragraph grids and each control's own width. Legacy pure migrations retain the original five saved keys, including clamped compass height offset.

## Bounded map textures

`./babylon` exports `createBoundedMapTextureLoader(ports)`, returning `load(file,request):Promise<LoadedMapTexture>`. `file` is the common images `ImageFile` with actual URL, PNG/JPEG MIME and positive pixel dimensions. The host supplies its existing `ImageSessionBroker`, `ImageFileService`, renderer `ImageTextureUploader`, actual `maxTextureSide()` and `whenReady(texture,signal)`. Request requires nonnegative encoded `declaredBytes`, finite `priority`, optional signal/overlap/onBytes. Source GPU capacity is admitted before decode/upload using a conservative full RGBA8 mip chain. Actual uploaded bytes replace that estimate after the uploader returns; NPOT GL1 omits illegal mips. Acquisition, encoded retention/header checks/decode queues/cache, native submission and the frame pump remain with their existing owners.

Upload uses kind `2d`, `textureColor:{useSRGBBuffer:false,gammaSpace:true}`, preserving source encoded-sRGB map storage with material gamma decoding. Renderer retains invertY=false, trilinear/mips where legal and actual device-size validation. Native upload and staging grants come directly from the common pools, so cancellation cannot release them before native work completes. The renderer owns late-copy cleanup. Engine adopts the returned texture into its operation scope, awaits host readiness, rejects stale generations and cleans encoded/decoded holds on every outcome. External abort listeners are removed on abort/disposal/generation loss.

`LoadedMapTexture` exposes `texture`, `uploaded`, `sourceGpuBytes`, `isCurrent()`, `dispose()` and `settleReplacement()`. Prepare hidden, await readiness, publish atomically, dispose outgoing content and only then settle the incoming overlap reservation. The map runtime already retains source CLAMP U/V material behavior; primary composition must preserve it when adopting the async handle. No engine map cache, decoder, uploader, device or frame scheduler is constructed here.

The original `createMapTextureLoader` remains the synchronous pending `Texture/updateURL` compatibility entry. Babylon hidden decode/upload in that path is not admitted by the shared broker. The optional asyncMapTextures runtime seam is now source-prepared and still requires truthful provider dimensions/MIME and primary-owned canonical adoption. The bounded loader does not pretend to be the old synchronous API or claim backend/color/device qualification.

## Prepared evidence and rollback

Retained source cases are layer registry, POI click threshold and culling. New cases cover disposal/suspension/late observers, custom horizon policy, pure defaults/refinement/migrations/settings, injected-document save refusal, supplied-canvas ownership/idle requests and bounded map reservations/cancellation/late native completion. `fixtures/visualization-consumer.mjs` is an isolated installed consumer of public exports, with pure-global rejection, explicit canvas/jsdom injection and common broker map lifecycle. `scripts/check-installed-consumer.mjs` requires exact packed dependency digests, checks every installed version and guards all ESM/CommonJS/declaration resolution against outside sources. Its NullEngine and mocked uploader fixtures are CPU-only; all are currently unrun.

Rollback keeps the canonical Earth source and its current atlas/legacy switch until packed adoption succeeds. Existing parameter IDs, default capacities/curves, layer lifecycle and saved-key migration remain available. New asynchronous map wiring and canvas device injection can be reverted independently at the host seam. Shared CI caller/conformance, clean human-attributed lineage, artifacts/export pins, consumer adoption and actual remote admission are pending primary/coordinator work.

The current [async raster, ordinary frame and cleanup renewal](async-raster-and-cleanup.md) documents actual public ports, ownership/compatibility changes, causal source cases and remaining Atlas/native/cache gates. All remain UNRUN.
